# Coastal erosion under compound storm surge

**Goal:** submitted to Journal of Coastal Systems by 2026-09-15
**People:** J. Halvorsen (lead), Mira Lindqvist (modelling), Tomas Reidar (field data)
**Canonical source:** Overleaf project `coastal-erosion-2026` (manuscript), Git repo `coastal-erosion-model` (code)
**Deadline:** 2026-09-15
**Part of:** `../../areas/nordblue-consortium` (work package 3)
**Started:** 2026-02-10

Modelling shoreline retreat under compound events, where storm surge and
sustained rainfall coincide. The existing regional model treats the two as
independent, which underestimates retreat on the north-facing stretches. We
have three seasons of field data from Sandvik that shows the interaction.
